# Posture Guard

Posture Guard 是以一般攝影機、OpenCV、MediaPipe 與 Tkinter 建立的桌面體態**篩檢與追蹤**工具。它用固定流程取得 2D 姿勢指標，並提供歷史紀錄及專業覆核入口。

> 本軟體不是醫療診斷工具，不能取代醫師或物理治療師評估。若有疼痛、麻木、外傷或症狀惡化，請直接就醫。

## 執行

```bash
python3 -m pip install -r requirements.txt
python3 testmail.py
```

首次開啟攝影機時，macOS 可能要求授權終端機或 Python 存取相機。

若啟動時出現 `需要 MediaPipe 0.10.x`，表示電腦安裝了新版 MediaPipe（1.x），其 API 與本專案目前採用的 Pose 介面不相容。請重新執行上方的安裝指令，並加上 `--upgrade`。

## 操作流程

1. 在「開始檢測」輸入匿名受測者編號。
2. 固定相機高度、距離及角度，讓受測者全身與雙腳入鏡。
3. 依序拍正面、左側、右側各三張。
4. 系統僅將關鍵點品質合格的影像納入量測。
5. 完成後可在「歷史趨勢」查看中位數與變化圖。
6. 專業人員可於「專業覆核」填入參考方法與結論，且不會覆寫系統原始值。

## CSV 資料設計

首次執行後會建立 `posture_data/`：

| 檔案 | 一列代表 | 用途 |
|---|---|---|
| `sessions.csv` | 一張合格影像 | 原始角度、視角與影像品質 |
| `summaries.csv` | 一次完整九張檢測 | 中位數、品質通過率與摘要 |
| `reviews.csv` | 一次專業覆核 | 人工參考方法與覆核結論 |
| `audit_log.csv` | 一個操作事件 | 建立、拍攝、重拍、完成、覆核的可追溯紀錄 |

CSV 為 UTF-8 with BOM，可直接由 Excel 開啟。匿名編號不是去識別化的唯一措施；研究使用時仍需依機構規範處理同意書、權限、保存與刪除政策。

## 指標與限制

- 正面：肩線傾斜、骨盆傾斜、左右腿角度。
- 側面：頭頸前移代理指標、膝關節角度。
- 頭頸數字是以 MediaPipe 耳／肩關鍵點計算的 **2D 代理指標**，不是以實體 C7 標記取得的臨床 CVA，不能直接作為診斷標準。
- 提醒閾值僅供篩檢與縱向追蹤；衣著、光線、體型、站姿、相機高度與距離都可能影響結果。

## 研究驗證建議

正式研究前，請先鎖定拍攝規範、適用族群與排除條件，再由專業人員依預先定義的參考方法進行盲性覆核。建議報告同日／跨日 ICC、系統與參考方法的 Bland–Altman 偏差與一致性範圍、影像拒絕率，以及本軟體與規則版本。未完成適用族群驗證前，不應宣稱診斷、治療或取代專業評估。
